# MyGit

## 时间同步助手（Windows 11）

默认同步北京时间，支持 Windows 全部时区、一键 NTP 校时和运行期间每小时自动同步。

- [下载最新版本](https://github.com/ZhuYongZheng0603/MyGit/releases/latest)
- [使用说明与源码](TimeSyncAssistant/README.md)

常见 Intel / AMD 电脑下载 `TimeSyncAssistant-win-x64.zip`，ARM 设备下载 `TimeSyncAssistant-win-arm64.zip`。解压后运行 `TimeSyncAssistant.exe`，按提示允许管理员权限即可，无需额外安装运行环境。
