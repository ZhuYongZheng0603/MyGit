# 时间同步助手 v1.0.0

Windows 11 中文桌面时间同步工具，默认同步北京时间。

- 新的「时钟 + 同步箭头」应用图标，适用于程序文件、窗口和任务栏。
- 一键修改系统时区并通过 NTP 校准系统时间，支持 Windows 全部时区及夏令时规则。
- 支持仅检测网络时间、自定义 NTP 服务器及备用服务器切换。
- 可在运行期间每 60 分钟自动同步，记住时区与服务器选择。
- 较大时间偏差需要手动确认；自动校时遇到较大偏差时跳过。

## 下载与使用

Intel / AMD 64 位电脑选择 **TimeSyncAssistant-win-x64.zip**，ARM64 电脑选择 **TimeSyncAssistant-win-arm64.zip**。解压并运行 `TimeSyncAssistant.exe`，允许管理员权限后点击「立即同步」。发布包自带运行时，无需另装 .NET。

`SHA256SUMS.txt` 提供文件校验值。程序尚未做商业代码签名，Windows 可能显示未知发布者。

已验证协议计算、无效响应处理、2036 年时间戳回绕、时区换算及本地 UDP 通信；发布流程会在 Windows 上编译并运行逻辑测试。尚未验证 Windows 11 图形界面和实际修改系统时钟的操作。
